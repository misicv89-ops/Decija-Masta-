# Vrtic Decija masta – sajt

Staticki sajt, spreman za GitHub Pages.

1. Napravite novi repozitorijum na GitHub-u i ubacite SADRZAJ ovog foldera (index.html mora biti u korenu).
2. Settings → Pages → Source: "Deploy from a branch" → main / (root) → Save.
3. Za sopstveni domen: Settings → Pages → Custom domain (npr. decijamasta.rs) i kod registra domena podesite DNS (CNAME na <korisnik>.github.io).
4. U index.html proverite adresu u og:url / og:image / twitter:image (trenutno https://decijamasta.rs/).
